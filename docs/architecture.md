# 설계 메모

## 원칙

1. **공간의 목적을 지킨다.** 각 공간은 빈 채팅창이 아니라 목적 버튼으로 시작한다. 집중 중에는 다른 공간으로 가는 메뉴를 숨긴다.
2. **연결은 보이게, 이동은 내가 고른다.**
   - 지금 일에 필요한 정보를 가져올 때: 출처와 반영 내용을 작게 표시 (`에너지 기록에서 가져왔어요`)
   - 다른 목적의 요청: *보관하기* 또는 *이동하기*를 내가 선택. 보관해도 조사·알림이 자동으로 시작되지 않는다.
3. **낮은 에너지 ≠ 쉬운 일.** 같은 중요한 일의 시작 단위와 시간을 줄인다 (`suggestFocus`).
4. **하루 예산은 하나.** 각 공간이 따로 할 일을 늘리지 않는다. 계획은 입구/오늘 화면에서만.

## 기억의 층

| 층 | 예시 | 공유 범위 |
|---|---|---|
| profile | 목표, 원칙, 선호 | 대부분의 공간 |
| 오늘 상태 (`checkins`) | 에너지, 기분 — 날짜와 함께 | 에너지 수준만 요약해서 공유. 기분·메모 원문은 에너지 공간에만 |
| 공간별 기록 | 집중 세션, 회고, 맡겨둔 생각 | 해당 공간 중심, 회고에서 모아 봄 |
| 확인한 패턴 (예정) | “회의 많은 날엔 짧은 세션이 잘 맞음” | 내가 확인한 것만 저장 |

공유 규칙은 `sharedContext()` 한 곳에 있고, 테스트로 원문 비공유를 확인한다.
