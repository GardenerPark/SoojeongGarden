하나 끝내고 다음 하나

하나는 떠오르는 생각은 언제든 쏟아내고, 지금의 하나에만 집중하게 돕는 하루 집중 앱입니다.

하루 흐름

  1. 아침 쏟아내기: 머릿속에 있는 걸 한 줄씩 적어요.
  2. 오늘의 하나: 오늘의 기준이 될 하나와, 썸(부가 우선순위)을 2개까지 골라요.
  3. 지금: "촬영 대본 정리 90분"처럼 말하듯 적고 시작해요. 화면에는 지금 블록 하나만 보여요.
  4. 쏟아내기: 집중하는 중에 떠오른 생각은 + 버튼, 단축어, 제어 센터로 던져 두세요.
  5. 전환 회고: 블록을 끝내면 쏟아낸 것을 지금 / 보관 / 지우기로 걸러요.
  6. 하루 마무리: 끝낸 하나의 수를 보고, 남은 것은 내일 아침 보관함으로 가요.

자주 묻는 것

잠금화면에 오늘의 하나를 띄우려면?

잠금화면을 길게 눌러 사용자화 → 잠금화면 → 위젯 추가 → 하나 → 오늘의 하나를 고르세요.

액션 버튼으로 바로 쏟아내려면?

설정 → 동작 버튼 → 단축어 → 하나 → "생각 던지기"를 고르세요. 누르고 말하면 앱을 열지 않고 저장돼요.

기록은 어디에 저장되나요?

내 아이폰 안에만 저장돼요. 자세한 내용은 개인정보처리방침을 봐 주세요.

음성 인식이 안 돼요.

설정 → 개인정보 보호 및 보안에서 마이크와 음성 인식을 허용했는지 확인해 주세요.
