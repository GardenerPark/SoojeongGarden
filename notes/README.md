# 생각과 자료 (메모 앱)

노션 **생각과 자료** DB에 담긴 생각을 아이폰 메모처럼 빠르게 쓰고, 태그별로 모아 읽는 개인용 웹앱입니다.
노션이 원본이고, 이 앱은 쓰고 훑어보기 편한 창구예요.

## 화면

| 화면 | 하는 일 |
|---|---|
| 전체 메모 | 제목 + 한 줄 생각(없으면 본문 앞부분). 최근 수정·이어 쓴 메모가 위로, 오늘/어제/지난 7일…로 묶음. 검색, 노란 연필 버튼으로 새 메모 |
| 태그별 모아보기 | 위쪽 태그(주제) 칩을 누르면 그 태그 메모만. 아래 작은 칩은 기록 유형(질문·단상 / 아이디어 / 정보·레퍼런스 / 경험·회고) |
| 개별 메모 | 첫 줄이 제목. 쓰면 자동 저장. 태그·분류·출처·활용처는 ⓘ를 눌렀을 때만, ↗는 노션 원본 |
| 생각 이어 쓰기 | 메모 아래에 덧붙이면 본문 끝에 `↳ 2026.11.01 14:30`과 함께 붙는다. 처음 담은 날짜는 그대로, 마지막 이어 쓴 시각을 따로 보여 줌 |

## 노션과 연결

| 노션 | 앱 |
|---|---|
| 생각 제목 | 제목 (메모 첫 줄) |
| 한 줄 생각 | 목록 미리보기 |
| 페이지 본문 | 메모 본문 |
| 주제 | 태그 |
| 기록 유형 | 분류 |
| 출처 · 활용처 · 영상 활용 · 정리 상태 · 관련 프로젝트 | 그대로 보존 (앱은 보여 주기만) |

- **저장 상태**: `저장 중…` / `노션에 저장됨` / `기기에 보관됨 · 연결되면 저장` / `동기화 실패 · 다시 시도` / `노션과 달라요`.
- **오프라인**: 쓴 내용은 먼저 기기(localStorage)의 보낼 함에 들어가고, 연결되면 보낸다(다시 연결될 때, 30초마다). 앱 껍데기는 서비스 워커가 저장해 두어 연결 없이도 열린다.
- **동시 수정**: 메모를 열었을 때의 버전(base)과 노션의 지금 버전, 내가 쓴 버전을 칸별(제목·본문·태그·분류)로 비교한다. 내가 고친 칸을 노션에서도 다르게 고쳤으면 덮어쓰지 않고 두 버전을 나란히 보여 준다 → **둘 다 남기기**(노션 버전 + 내 글을 이어 쓰기로) / 내 버전으로 저장 / 노션 버전 쓰기. 내가 안 고친 칸의 노션 변경은 그대로 둔다.
- **앱이 안전하게 고칠 수 없는 내용**: 표·이미지·토글·하위 블록, 굵기·색·링크 같은 서식이 하나라도 있는 메모는 본문을 앱에서 바꾸지 않는다. 내용은 읽기용으로 보여 주고 **원본 보기**로 연다. 제목·태그 수정과 이어 쓰기는 된다.
- **본문 저장 방식**: 바뀐 줄만 고친다(같은 줄은 그대로, 바뀐 줄은 같은 블록 내용만 수정, 새 줄은 그 자리에 끼워 넣기). 문단·제목(`#`)·목록(`-`, `1.`)·할 일(`[ ]`)·인용(`>`)·구분선(`---`)을 줄 앞 표시로 주고받는다.
- **하지 않는 것**: 메모 삭제, DB 구조 변경(새 태그 만들기 포함). 태그는 노션에 이미 있는 주제에서 고른다.
- 노션 토큰은 서버 환경변수에만 있고 화면·응답·코드에 나가지 않는다.

## 실행

```bash
cd notes
npm run demo         # 노션 없이 예시 메모로 체험 → http://localhost:8200 (끄면 사라짐)
npm start            # 노션 연결 (아래 설정 필요)
npm test
```

의존성 없음 (Node 18+).

### 노션 연결 (처음 한 번)

1. [노션 연결 관리](https://www.notion.so/profile/integrations)에서 **내부 연결**을 만들고 토큰을 복사한다. 권한: 콘텐츠 읽기·업데이트·삽입.
2. 노션에서 **생각과 자료** DB 페이지 → `⋯` → **연결** → 방금 만든 연결 추가.
3. `notes/.env.example`을 `notes/.env`로 복사해 `NOTION_TOKEN=`에 붙여 넣는다.

| 환경변수 | 기본값 | 뜻 |
|---|---|---|
| `NOTION_TOKEN` | 없음 | 노션 연결 토큰 (서버에만) |
| `NOTES_DB_ID` | 생각과 자료 DB | 다른 DB를 쓸 때 |
| `NOTES_TOKEN` | 없음 | 앱 접속 비밀번호. 정하면 0.0.0.0에서 열어 휴대폰에서 접속 가능 |
| `NOTES_TZ` | `Asia/Seoul` | 이어 쓰기 시각 기준 |
| `PORT` | 8200 | |

### 아이폰에서 쓰기 (Vercel)

`notes/`를 루트로 하는 Vercel 프로젝트로 올리면 된다 (`vercel.json`, `api/index.js`). 프로젝트 환경변수에 `NOTION_TOKEN`, `NOTES_TOKEN`(필수, 없으면 API가 열리지 않음)을 넣는다.
Safari에서 `https://<주소>/?token=<NOTES_TOKEN>`을 한 번 열면 토큰이 기기에 저장되고 주소창에서 지워진다. 공유 → **홈 화면에 추가**.

## 구조

```
blocks.js       노션 블록 ↔ 줄, 단순 블록 판별, 줄 단위 차이 계산, 이어 쓰기 표시
service.js      ops: meta / list / get / create / save(3방향 비교) / append
notion.js       노션 API 클라이언트 (재시도, 동시 요청 3개 제한)
fake-notion.js  메모리 위의 가짜 노션 (테스트·체험 모드)
http.js         /api/<op> 처리 (로컬 서버와 Vercel 함수가 같이 씀)
setup.js        환경변수 → 서비스
server.js       로컬 서버
api/index.js    Vercel 함수
web/            모바일 웹앱 (보낼 함, 충돌 화면, 서비스 워커)
```

## 아직 없는 것

- 노션에서 바뀐 내용은 목록을 열 때·메모를 열 때 가져온다(실시간 푸시 아님).
- 검색은 제목·한 줄 생각·태그·미리보기와, 이 기기에서 한 번 열어 본 메모의 본문까지.
- 서식(굵기·색) 편집, 이미지 첨부, 새 태그 만들기, 메모 삭제.
